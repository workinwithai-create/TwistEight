# TwistEight

Eight-bar twist desk for bedroom producers stuck in loops.

Loops photocopy themselves. Session players add a harmonic turn, a counter-line, or a rhythmic hitch so the section can leave and the track can finish.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight bank pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`.

No oscillators. Audio never leaves the tab.

## Distinct from yesterday and the rest of the line

Not TagFour (last-line end tag), LiftTwo (two-bar pre-hook lift), PreEight (eight-bar musical pre-chorus), AfterHook, EndEight, LastHook, ArcEight (energy arc), StackEight (density stack).
